# Mac App Store (`mas`) Apps Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Declarative Mac App Store apps by ID in `packages.mas`, with install/remove under `uninstall_mode`, upgrade, and import — driven by the `mas` CLI (not Brewfile).

**Architecture:** Decode nix-darwin-style name→ID maps into `MasApp` + `MasConfigured`. Discover via `mas list`/`outdated`, plan `mas_install`/`mas_remove`/`mas_upgrade`, apply with a dedicated Mas runner. Ensure the `mas` formula when MAS is managed. Extend packages import formatting/merge.

**Tech Stack:** Go, Lua config decode, existing brew plan/exec/import patterns

**Design:** `docs/plans/2026-08-15-mas-apps-design.md`
