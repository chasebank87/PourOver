# macOS Defaults Import Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add `pourover import macos` that snapshots every readable curated catalog key into `macos.lua` so apply can recreate the Mac’s settings (lock screen text, trackpad, keyboard, etc.).

**Architecture:** Catalog-driven pipeline — flatten `macos_catalog.yaml` → `defaults read` each key via existing `DefaultsRunner` → merge/force into Lua via `configimport` → engine façade + CLI subcommand. Expanding coverage = edit the catalog only.

**Tech Stack:** Go, existing `config.Catalog`, `discovery.DefaultsRunner` / `ParseDefaultsRead`, `configimport`, cobra, engine

**Design:** `docs/plans/2026-08-15-macos-defaults-import-design.md`
